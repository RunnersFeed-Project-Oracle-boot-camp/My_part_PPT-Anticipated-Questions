## 파일

- `Runners_Eye_Full_with_Personal_Part.pptx`: 전체 발표자료에 개인 담당 2장을 반영한 통합본
- `Runners_Eye_Personal_Part_2slides.pptx`: 영상 조건 표준화와 GPU 성능 비교를 담은 개인 담당 자료

## 개인 담당 범위

사용자 영상의 FPS, 해상도, 압축 조건을 검토하고 처리시간과 자원 사용량을 모니터링했습니다. 동일한 약 4.25초 영상을 CPU와 GPU에서 각각 두 차례 처리해 GPU 적용에 따른 시간 단축을 확인했습니다.
